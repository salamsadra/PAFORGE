# راهنمای سریع PAForge

برای اجرا Python 3.10 یا جدیدتر لازم است. در macOS و Linux از پوشهٔ اصلی نرم‌افزار دستور زیر را اجرا کنید:

```bash
bash PAForge_Launch.sh
```

در Windows فایل `PAForge_Launch_Windows.bat` را اجرا کنید. رابط کاربری در نشانی http://127.0.0.1:7860 در دسترس است. نصب اولیه ممکن است به اینترنت نیاز داشته باشد.

برای تولید دادهٔ عددی و دادهٔ مبتنی بر اطلاعات تجربی، دستورهای [README](../README.md) را دنبال کنید. داده‌های اصلی تجربی را جداگانه از ناشر دریافت کنید. مولد `empirical_material` نیازمند آموزش شبکهٔ عصبی نیست.

برای بازسازی دادهٔ اندازه‌گیری‌شده به [Measured data](MEASURED_DATA.md) و برای تبادل HDF5 با MATLAB به [MATLAB interoperability](MATLAB_HDF5_INTEROP.md) مراجعه کنید. نرم‌افزار یک ابزار پژوهشی عددی دوبعدی است؛ خروجی مصنوعی با اندازه‌گیری تجربی یکسان نیست.
